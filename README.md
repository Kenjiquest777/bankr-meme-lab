# Bankr Meme Lab

**Bankr Meme Lab** is a post-ready meme generator app themed around Bankr, $BNKR, and the Base agentic economy.

## Features
- **Curated Meme Pool**: Instant random drops across various formats (Drake, Distracted Boyfriend, Gru's Plan, This Is Fine, Galaxy Brain, Wojak, and more).
- **Topic Filters**: Filter memes by topics like `agent life`, `deploys`, `volatility`, `club`, `lore`, `ham & mfers`, `beef & fud`, `base`, `wojak`, `self-grill`, `cope`, `trench life`, and `dev pain`.
- **Custom Builder**: Select from custom meme templates and generate custom multi-line text memes on demand.
- **One-Click Actions**: Easily copy image links, captions, open full-size renders, or remix directly in chat.

## Custom Template Breakdowns
- **Aristocrat**: Top and bottom comment sections.
- **Star Wars Anakin**: 4-panel series with comment slots at the bottom of panel 1 (Anakin), panel 2 (Padme), and panel 4 (Padme).
- **Bernie Sanders Support**: Single-line auto-scaling comment slot directly underneath "I am once again asking for your support".
- **Conspiracy Meme**: Top and bottom text sections mapped to memegen native engine.
- **Gary Gensler**: Comment section at the bottom.
- **Two Buttons Meme**: Strategic comment slots above the left button, above the right button, and on the bottom sweating guy panel.
- **Dwight Schrute**: Restored in Beef & FUD category with custom question and statement slots.
- **Is This A Pigeon?**: Auto-scaling object label and guy/question slots.

## Running Locally
Simply open `index.html` in any web browser. No build steps or external dependencies required.
