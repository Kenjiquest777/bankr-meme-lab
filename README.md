# Bankr Meme Lab

**Bankr Meme Lab** is a post-ready meme generator app themed around Bankr, $BNKR, and the Base agentic economy.

## Features
- **Curated Meme Pool**: Instant random drops across various formats (Drake, Distracted Boyfriend, Gru's Plan, This Is Fine, Galaxy Brain, Wojak, and more).
- **Topic Filters**: Filter memes by topics like `agent life`, `deploys`, `volatility`, `club`, `lore`, `ham & mfers`, `beef & fud`, `base`, and `wojak`.
- **Custom Builder**: Select from 30 meme templates and generate custom multi-line text memes on demand.
- **One-Click Actions**: Easily copy image links, captions, open full-size renders, or remix directly in chat.

## Running Locally
Simply open `index.html` in any web browser. No build steps or external dependencies required.
